# Дайджесты

Архив всех прогонов в git. **Не удалять** старые файлы.

| Файл | Назначение |
|------|------------|
| `YYYY-MM-DD.md` | полный дайджест за дату |
| `YYYY-MM-DD.cards.json` | карточки для кнопок TG за ту же дату |

Актуальные копии в корне: `../latest.md`, `../digest_cards.json` (перезаписываются каждым прогоном).
