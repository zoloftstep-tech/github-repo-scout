# github-repo-scout

Еженедельный поиск проверенных GitHub-репозиториев под задачи Ростислава (security-gate + персональный дайджест).

- Инструкция: [`PROMPT.md`](./PROMPT.md)
- Категории: [`interests.json`](./interests.json)
- Уже показанные: [`seen_repos.json`](./seen_repos.json)
- Дайджесты: `digests/YYYY-MM-DD.md`, актуальный — [`latest.md`](./latest.md)

**Расписание (рекомендуемое):** воскресенье 06:00 Europe/Minsk, результат к 10:00. Cron UTC: `0 3 * * 0`.
